# @teraprox/ui-kit-sgm

Widgets visuais do domínio SGM (Manutenção) — formulários, modais e displays específicos consumidos por `SGM-OS`, `SGM-SS`, `SGM-OM` e `SGM-UTILS`.

**Status:** skeleton vazio criado na Wave 0 da sprint `2026-04-21-ui-kit-domain-split-wave0`. Componentes serão migrados gradualmente a partir de `teraprox-ui-kit` na Wave 2.

Consumido via meta-package `teraprox-ui-kit@>=0.2.0` enquanto a transição está em andamento; remotes passarão a importar diretamente a partir da Wave 4.
