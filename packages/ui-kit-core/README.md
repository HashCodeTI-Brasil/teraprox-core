# @teraprox/ui-kit-core

Primitivos visuais cross-cutting (buttons, forms, displays, containers) compartilhados entre os micro-frontends dos domínios SGM (Manutenção) e SGP (Processo).

**Status:** skeleton vazio criado na Wave 0 da sprint `2026-04-21-ui-kit-domain-split-wave0`. Componentes serão migrados gradualmente a partir de `teraprox-ui-kit` nas Waves 1-3.

Consumido via meta-package `teraprox-ui-kit@>=0.2.0` enquanto a transição está em andamento; remotes passarão a importar diretamente a partir da Wave 4.
